# Page-level Templates

- ArticlePage: blog/article template with hero, breadcrumbs and metadata
- AboutPage: an about page from `about.md`, with AboutPage structured data and room for author cards
- ContactPage: a contact form under the page title, with optional Markdown and ContactPage structured data
- NotFoundPage: a noindex 404 page with a home link, search and suggestions
- ContentListPage: blog index, category, tag and author pages with an `h1`, pagination and feed links
- DocumentPage: documentation page layout with TOC
- LandingPage: marketing landing template with sections
- HomePage: starter homepage template
